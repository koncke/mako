# VSL · MaKo, tu consultor (Second Brain)

> **Para:** el dueño que decide solo, de noche y a ojo · **Ángulo:** no es un chatbot; es alguien que conoce tu negocio entero
> **Dura:** ~1:40 · **CTA:** Entra a MaKo (o agenda tu diagnóstico) · **Landing:** Second Brain

**La idea en una frase:** le preguntas a MaKo como a un socio que leyó todo tu negocio, y te contesta con tus números.

## Guion

**GANCHO (0:00–0:12)** [una pantalla de ChatGPT en blanco]
Le preguntas a ChatGPT cómo vender más. ///
Y te contesta lo mismo que a **todo el mundo**.

**DOLOR (0:12–0:35)**
Porque no sabe nada de ti. // Ni tu oferta. // Ni tus anuncios. // Ni por qué se te cayeron las ventas el martes. ///
Así que terminas decidiendo como siempre: // solo, // a las once de la noche, // **con una corazonada**. ///
Y nadie te avisa que algo se rompió… // hasta que ya te costó dinero.

**MAKO (0:35–1:12)** [la estrella de MaKo abriéndose en distintas pantallas]
MaKo es distinto. // Desde el primer día conoce tu negocio: // tu oferta, // tu cliente ideal, // tu forma de vender. ///
Y ve lo mismo que tú: // tus anuncios, // tus leads, // tus llamadas, // tus cobros. ///
Está en cada pantalla. // Le preguntas «¿por qué bajaron las agendas?» // y te contesta **con tus números**. ///
Y cuando algo urge, // no espera a que preguntes: // te avisa por WhatsApp.

**PRUEBA (1:12–1:24)** [una pregunta real y su respuesta, sostenida]
Una pregunta. // Una respuesta con tu dato de ayer, // no con un consejo de manual.

**OBJECIÓN (1:24–1:35)**
Y si tu objeción es «ya uso ChatGPT»… // déjame decirte algo: ///
ChatGPT sabe mucho de todo. // **MaKo sabe todo de ti.**

**CIERRE (1:35–1:40)**
No te falta información. // Te falta alguien que la lea por ti. /// Entra a MaKo.

## 3 ganchos para testear
1. «ChatGPT te contesta lo mismo que a todo el mundo.»
2. «¿Quién te avisa cuando tu negocio se rompe?»
3. «Un consultor que leyó tu negocio entero.»

## Lo que NO dice, a propósito
- Qué modelo de IA usa: cada negocio conecta su IA (Claude, ChatGPT o Gemini); eso va en la landing, no en el video.
- Que MaKo «hace» cosas solo: desde el chat propone y la persona confirma.
