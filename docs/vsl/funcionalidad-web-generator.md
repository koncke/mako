# VSL · Web Generator

> **Para:** el que depende de un diseñador para cada landing · **Ángulo:** tu próxima landing no puede tardar dos semanas
> **Dura:** ~1:35 · **CTA:** Entra a MaKo (o agenda tu diagnóstico) · **Landing:** Web Generator

**La idea en una frase:** le cuentas a MaKo qué vendes y te arma la landing con tu video, lista para publicar.

## Guion

**GANCHO (0:00–0:12)** [un calendario con dos semanas tachadas]
Tienes una idea para un anuncio nuevo. ///
Y la landing… // **llega en dos semanas.**

**DOLOR (0:12–0:35)**
Le escribes al diseñador. // Esperas. // Corriges. // Vuelves a esperar. ///
Y cuando por fin está, // el anuncio que querías probar // **ya no te parece buena idea**. ///
O peor: // la armas tú, // con una plantilla // que se parece a la de todos.

**MAKO (0:35–1:08)** [el editor del Web Generator]
En MaKo le cuentas qué vendes. // Y la landing se arma en minutos. ///
Con tu video arriba, // tu oferta, // tus testimonios // y el botón para agendar. ///
¿Quieres cambiar un título? // Lo tocas y listo. // ¿Una imagen? // Se la pides a MaKo. ///
Y cuando alguien entra, // lo ves en su ficha: // si vio tu video // y hasta dónde.

**PRUEBA (1:08–1:20)** [una landing armándose de cero]
De la idea // a la landing publicada, // en lo que tardas en tomarte un café.

**OBJECIÓN (1:20–1:30)**
Y si tu objeción es «no sé de diseño»… // déjame decirte algo: ///
no hace falta. // **Tú pones lo que vendes. MaKo pone el diseño.**

**CIERRE (1:30–1:35)**
El que prueba más rápido, // aprende primero. /// Entra a MaKo.

## 3 ganchos para testear
1. «Tu landing no puede tardar dos semanas.»
2. «De la idea a la landing, en minutos.»
3. «¿Sigues esperando al diseñador?»

## Lo que NO dice, a propósito
- Antes de grabar «lo ves en su ficha: si vio tu video y hasta dónde», confirmar que una landing publicada desde el
  Web Generator ya trae el seguimiento del video (el del VSL de `/` sí lo trae). Si no, se corta esa frase.
- «En lo que tardas en tomarte un café» es una imagen, no un tiempo medido: si Martín prefiere un número,
  hay que cronometrar una landing real antes de decirlo.
