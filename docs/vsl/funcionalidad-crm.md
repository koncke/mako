# VSL · CRM

> **Para:** el que tiene los leads desparramados entre WhatsApp, formularios y la libreta · **Ángulo:** el lead no dijo que no; lo abandonaste
> **Dura:** ~1:40 · **CTA:** Entra a MaKo (o agenda tu diagnóstico) · **Landing:** CRM

**La idea en una frase:** MaKo te arma la ficha de cada lead con de dónde vino y qué pasó, y te dice a quién atender.

## Guion

**GANCHO (0:00–0:12)** [texto gigante: «¿Quién?»]
¿Cuántos leads te escribieron esta semana? ///
Ahora la difícil: // ¿**quién** de ellos está esperando tu respuesta… // desde hace tres días?

**DOLOR (0:12–0:35)** [chats de WhatsApp apilándose]
Los nombres están en WhatsApp. // Los datos, en el formulario. // Las notas de la llamada, // en tu cabeza. ///
Y tu CRM… // si lo tienes, // es una **ficción ordenada**: // prolijo, lleno, // y sin decirte nada. ///
El lead no dijo que no. // **Lo abandonaste.**

**MAKO (0:35–1:10)** [el tablero del CRM real]
Con MaKo, cada persona que deja sus datos // o te escribe por WhatsApp // tiene su ficha. // Sin que la cargues. ///
Ahí ves de qué anuncio vino, // qué le escribiste, // si agendó // y si te pagó. ///
Cuando termina una llamada, // la grabación queda en su ficha. ///
Y MaKo te propone el siguiente paso: // a quién moverle la etapa, // a quién escribirle hoy. ///
Tú confirmas con un toque. // Él hace el resto del papeleo.

**PRUEBA (1:10–1:22)** [una ficha real, sostenida]
Una ficha. // Todo lo que pasó con esa persona, // del anuncio al pago, // en una pantalla.

**OBJECIÓN (1:22–1:35)**
Y si tu objeción es «no tengo tiempo de cargar otro CRM»… // déjame decirte algo: ///
ése es el punto. // **Éste no lo cargas tú.**

**CIERRE (1:35–1:40)**
Los leads no se pierden por precio. // Se enfrían porque nadie los sigue. /// Entra a MaKo.

## 3 ganchos para testear
1. «El lead no dijo que no. Lo abandonaste.»
2. «Tu CRM está lleno. Y no te dice nada.»
3. «¿Quién te escribió hace tres días y sigue esperando?»

## Lo que NO dice, a propósito
- **Que MaKo mueve los leads solo:** hoy propone y la persona confirma.
- El «nueve de cada diez» de los guiones viejos: lo medido era 7 de 10 y no se volvió a medir.
