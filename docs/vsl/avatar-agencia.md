# VSL · Avatar: agencia o trafficker

> **Para:** el que maneja los anuncios de varios clientes y vive mandando reportes · **Ángulo:** tu cliente no te paga por leads; te paga por ventas
> **Dura:** ~1:45 · **CTA:** Agenda tu diagnóstico gratis · **Empuja:** MaKo Pro (US$97, el modo agencia) · **Landing:** por avatar

**La idea en una frase:** con MaKo le muestras a cada cliente las ventas que trajeron tus anuncios, no sólo los leads.

## Guion

**GANCHO (0:00–0:12)** [un mensaje de WhatsApp: «¿y esos leads compraron?»]
Tu cliente te escribe: // «los leads son malos». ///
¿Cómo le **demuestras** que no?

**DOLOR (0:12–0:40)**
Tú le traes leads. // Lo que pasa después // pasa en el WhatsApp de tu cliente, // en su calendario // y en su cuenta de banco. ///
Tú no lo ves. ///
Entonces el reporte del mes // es un costo por lead // y una promesa. ///
Y cuando las ventas bajan, // la culpa es **del que pauta**. // Siempre.

**MAKO (0:40–1:18)** [la barra de agencia pasando de un cliente a otro]
Con MaKo, // cada cliente tiene su espacio: // sus anuncios, // sus leads, // sus llamadas // y sus cobros. ///
Y tú pasas de uno a otro // sin cerrar sesión. ///
Al lado de cada anuncio // ves cuántas llamadas agendó // y cuánto dinero cobró tu cliente de ahí. ///
Y si el problema no es el anuncio // sino el seguimiento, // lo ves. // **Y se lo puedes mostrar.**

**PRUEBA (1:18–1:30)** [la tabla de anuncios con la columna de dinero cobrado]
Un anuncio. // Cuarenta leads. // Tres ventas. // Ese número ya no se discute.

**OBJECIÓN (1:30–1:40)**
Y si tu objeción es «mis clientes no van a querer otra herramienta»… // déjame decirte algo: ///
no tienen que aprender nada. // **Les llega el resultado.**

**CIERRE (1:40–1:45)**
Deja de vender leads. // Empieza a mostrar ventas. /// Agenda tu diagnóstico gratis.

## 3 ganchos para testear
1. «Tu cliente dice que los leads son malos. ¿Y si no?»
2. «Deja de vender leads. Muestra ventas.»
3. «¿Cuánto vendió tu cliente con tus anuncios?»

## Lo que NO dice, a propósito
- El precio por cliente (cada espacio de cliente paga su plan): va en la llamada.
- «Les llega el resultado» = el cliente ve su propio MaKo; los reportes automáticos por WhatsApp son al dueño de cada
  espacio. No prometer un reporte de agencia con su marca.
