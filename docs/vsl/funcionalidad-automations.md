# VSL · Automations (seguimiento por WhatsApp)

> **Para:** el que vende por WhatsApp y no llega a escribirle a todos · **Ángulo:** el dinero está en el seguimiento
> **Dura:** ~1:40 · **CTA:** Entra a MaKo (o agenda tu diagnóstico) · **Landing:** Automations

**La idea en una frase:** dibujas una vez cómo le escribes a un lead y MaKo hace el seguimiento hasta que contesta.

## Guion

**GANCHO (0:00–0:12)** [texto gigante: «5»]
Ocho de cada diez ventas // llegan después del **quinto** mensaje. ///
¿Hasta qué mensaje llegas tú?

**DOLOR (0:12–0:35)** [un chat con un solo mensaje, en visto]
Le escribes una vez. // No contesta. // Te olvidas. ///
No porque no te importe. // Porque son cuarenta chats, // y tú eres uno solo. ///
Y ese lead que pagó el anuncio… // se lo queda **el que sí volvió a escribirle**.

**MAKO (0:35–1:12)** [el lienzo de Automations, tarjeta por tarjeta]
Con MaKo dibujas el camino una vez. // Como un mapa. ///
El primer mensaje. // Si no contesta, // esperas dos días // y va el segundo. // Y el tercero. ///
Si contesta, // MaKo lee qué dijo. // Si quiere agendar, // le pasa tu calendario. // Si dice que no, // lo deja tranquilo. ///
Y a ti te avisa por WhatsApp // cuando alguien responde. ///
Los mensajes salen de tu número, // en tu horario, // de a poco. // Como si los mandaras tú.

**PRUEBA (1:12–1:24)** [un flujo real: apertura → espera → «¿Contestó?» → seguimiento]
Un flujo. // Cuatro tarjetas. // Cada lead nuevo pasa por ahí, // sin que tengas que acordarte.

**OBJECIÓN (1:24–1:36)**
Y si tu objeción es «no quiero sonar a robot»… // déjame decirte algo: ///
los mensajes los escribes tú, // con tus palabras. // MaKo sólo elige **cuándo** mandarlos.

**CIERRE (1:36–1:40)**
El dinero no está en el primer mensaje. // **Está en el que nadie manda.** /// Entra a MaKo.

## 3 ganchos para testear
1. «¿Hasta qué mensaje le haces seguimiento a un lead?»
2. «Le escribiste una vez. Tu competencia, cinco.»
3. «El dinero está en el seguimiento.»

## Lo que NO dice, a propósito
- El «ocho de cada diez después del quinto contacto» es un dato de mercado que circula sin fuente firme: si Martín
  prefiere no usarlo, el gancho alternativo es el 2.
- Que MaKo «contesta solo» cualquier cosa: el AI Step clasifica la respuesta y necesita la IA del negocio conectada;
  sin IA, avisa y responde una persona.
- La aprobación mensaje por mensaje: Martín (23/10) «si estoy haciendo una AUTOMATIZACIÓN es OBVIO que debe llegar
  sola». La objeción se contesta con que el texto es suyo.
