# VSL · Dashboards

> **Para:** el que mira cinco pantallas para saber si el mes va bien · **Ángulo:** del anuncio al cobro, en una sola pantalla
> **Dura:** ~1:40 · **CTA:** Agenda tu diagnóstico gratis · **Empuja:** Esencial (Pro, el dashboard completo) · **Landing:** `/vsl/dashboards`

**La idea en una frase:** MaKo junta tus anuncios, tu landing, tus llamadas y tus cobros en un dashboard que te dice qué mover hoy.

## Guion

**GANCHO (0:00–0:12)** [texto gigante: «¿cuánto?»]
Si hoy te preguntan cuánto te costó cada cliente que te pagó este mes… ///
¿cuánto tardas en contestar?

**DOLOR (0:12–0:38)** [pestañas apilándose: Meta, Calendly, Stripe, la planilla]
Abres Meta. // Después tu calendario. // Después Stripe. // Después la planilla donde anotas a mano. ///
Y cuando terminas de cruzar todo… // el número ya cambió. ///
Así que decides con **la sensación** de cómo va el mes. // Y la sensación // siempre llega tarde.

**MAKO (0:38–1:15)** [el editor de Dashboard de MaKo con sus gráficos]
En MaKo, tus anuncios, // tu landing, // tus llamadas // y tus cobros // viven en el mismo lugar. ///
Armas tu dashboard como una hoja: // eliges qué ver // y se actualiza solo. ///
Ves qué anuncio trae clientes **que pagan**, // no sólo clics. ///
Y si un número no se entiende, // le preguntas a MaKo // qué está pasando // y qué mover hoy.

**PRUEBA (1:15–1:28)** [un gráfico real: gasto contra dinero cobrado]
Un gráfico. // Lo que gastaste en anuncios // contra lo que cobraste. // Mes por mes.

**OBJECIÓN (1:28–1:37)**
Y si tu objeción es «ya tengo Looker o una planilla»… // déjame decirte algo: ///
esos te muestran **lo que les cargas**. // MaKo ya tiene los datos adentro.

**CIERRE (1:37–1:40)**
Un número a tiempo vale más que diez tarde. /// Agenda tu diagnóstico gratis.

## 3 ganchos para testear
1. «¿Cuánto te costó cada cliente que te pagó este mes?»
2. «Tu dashboard te muestra clics. ¿Y las ventas?»
3. «Del anuncio al cobro, en una sola pantalla.»

## Lo que NO dice, a propósito
- «Qué mover hoy» es MaKo contestando sobre el gráfico o el semáforo; no promete que mueva nada solo.
- El dashboard completo (con Ads Manager) es del plan Pro; el básico viene en Esencial.
