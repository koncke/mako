# VSL · Avatar: inmobiliarias

> **Para:** dueño o director de una inmobiliaria que pauta en Meta y reparte interesados entre asesores
> **Ángulo:** el interesado que no recibe respuesta en minutos le compra a otro
> **Dura:** ~1:45 · **CTA:** Agenda tu diagnóstico gratis · **Empuja:** Pro (varias líneas y equipo) o el Acelerador · **Landing:** `/vsl/inmobiliarias`

**La idea en una frase:** cada interesado recibe respuesta y seguimiento al instante, y ves qué campaña trae las operaciones que cierran.

## Guion

**GANCHO (0:00–0:12)** [un WhatsApp: «¿sigue disponible?», enviado hace 3 horas]
Un interesado pregunta: // «¿sigue disponible?». ///
Tu asesor contesta **tres horas después**. // ¿Adivinas quién le vendió?

**DOLOR (0:12–0:40)**
Pagas anuncios para que te escriban. // Te escriben. ///
Y después el mensaje cae en el teléfono de un asesor… // que está mostrando otra propiedad. ///
Nadie sabe quién respondió, // quién hizo seguimiento // ni qué campaña trajo la operación que cerró. ///
Tu inmobiliaria no pierde clientes por precio. // **Los pierde por demora.**

**MAKO (0:40–1:18)** [el CRM con los interesados y sus asesores]
Con MaKo, // cada interesado que llega del anuncio // tiene su ficha. ///
Recibe respuesta por WhatsApp al instante, // y seguimiento si no contesta. ///
Tus asesores trabajan sobre la misma lista, // cada uno con lo suyo. ///
Y tú ves algo que hoy no ves: // **qué campaña trae las operaciones que cierran**, // no sólo los mensajes.

**PRUEBA (1:18–1:30)** [la tabla de anuncios con la columna de operaciones cerradas]
Una campaña. // Ochenta interesados. // Las operaciones que cerró. // Ese es el número que importa.

**OBJECIÓN (1:30–1:40)**
Y si tu objeción es «mis asesores no van a usar otra herramienta»… // déjame decirte algo: ///
siguen en WhatsApp. // **MaKo ordena lo que ya hacen.**

**CIERRE (1:40–1:45)**
En inmobiliaria gana el que contesta primero. /// Agenda tu diagnóstico gratis.

## 3 ganchos para testear
1. «¿Sigue disponible? Tu asesor contestó tres horas después.»
2. «Tu inmobiliaria no pierde clientes por precio. Los pierde por demora.»
3. «¿Qué campaña te trajo la última operación que cerraste?»

## Lo que NO dice, a propósito
- Nombres ni números de inmobiliarias que usan MaKo: hay clientes del rubro, pero ninguno autorizó su caso.
- Los «ochenta interesados» de la PRUEBA son una pantalla de ejemplo: grabarla con datos de prueba o tapados.
