# VSL · Offer

> **Para:** el que tiene un buen servicio y una oferta que no se entiende · **Ángulo:** no te falta tráfico; te falta una oferta que se compre sola
> **Dura:** ~1:35 · **CTA:** Entra a MaKo (o agenda tu diagnóstico) · **Landing:** Offer

**La idea en una frase:** MaKo te hace las preguntas de un experto en ofertas y te devuelve la tuya escrita, lista para vender.

## Guion

**GANCHO (0:00–0:12)** [texto gigante: «¿Y qué incluye?»]
Si tu cliente te pregunta «¿y qué incluye?»… ///
**tu oferta ya perdió.**

**DOLOR (0:12–0:35)**
Sabes que lo tuyo funciona. // Tus clientes lo dicen. ///
Pero cuando lo escribes, // es una lista de sesiones, // horas // y módulos. ///
Y el que lo lee no ve lo que gana. // Ve **lo que le cuesta**. ///
Entonces bajas el precio. // Y vendes igual de poco.

**MAKO (0:35–1:08)** [el chat de Offer haciendo preguntas]
En MaKo, armas tu oferta conversando. ///
MaKo te hace las preguntas que te haría un experto: // a quién le vendes, // qué problema le sacas de encima, // qué te hace distinto. ///
Te dice qué le falta a lo que tienes hoy. ///
Y te devuelve tu oferta escrita: // la promesa, // lo que incluye, // por qué vale lo que cuesta. ///
Lista para tu landing, // tu video // y tu llamada de venta.

**PRUEBA (1:08–1:20)** [el antes y el después de una oferta]
Antes: // «ocho sesiones de una hora». ///
Después: // lo que tu cliente **va a tener** al terminar.

**OBJECIÓN (1:20–1:30)**
Y si tu objeción es «mi negocio es distinto»… // déjame decirte algo: ///
por eso las preguntas son sobre **tu** negocio. // No hay plantilla.

**CIERRE (1:30–1:35)**
Una oferta clara no se explica. // Se compra. /// Entra a MaKo.

## 3 ganchos para testear
1. «Si te preguntan qué incluye, tu oferta ya perdió.»
2. «No bajes el precio. Cambia la oferta.»
3. «¿Tu cliente entiende lo que gana contigo?»

## Lo que NO dice, a propósito
- Nombres de metodologías o de autores: el criterio vive en la app; en el video no se nombra a nadie.
