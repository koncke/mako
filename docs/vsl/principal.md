# VSL principal · MaKo

> **Para:** todo el que llega del anuncio · **Ángulo:** inviertes en anuncios y no sabes cuál te trae clientes
> **Dura:** ~2:20 · **CTA:** Agenda tu diagnóstico gratis · **Landing:** `/`

**La idea en una frase:** tus datos de venta viven en cinco apps que no se hablan; MaKo los junta y te dice qué hacer.

## Guion

**GANCHO (0:00–0:15)** [texto gigante: «¿cuál?»]
Inviertes en anuncios todos los meses. ///
Hazte una pregunta incómoda: // ¿sabes **cuál** de esos dólares te trajo un cliente… // y cuál se quemó?

**DOLOR (0:15–0:45)** [logos de Meta, Calendly, WhatsApp, Excel, uno por frase]
Meta te dice que tu anuncio va bien. // Calendly, que tienes agendas. // WhatsApp, cien chats sin contestar. //
Y tu planilla, que cobraste menos de lo que creías. ///
Cinco apps. // Cinco versiones de la verdad. // Y tú en el medio, // uniendo los pedazos a las once de la noche. ///
Eso no es tener un sistema. // **Es tener una intuición.**

**MAKO (0:45–1:30)** [entra la estrella de MaKo]
Aquí es donde entra MaKo. ///
Un software hecho para una sola cosa: // que tu vsl funnel **venda más**. ///
Del primer clic en tu anuncio… // hasta el cliente que paga. // En un solo lugar. ///
Conectas tus anuncios, tu landing, tu WhatsApp, tu calendario y tus cobros. ///
Y por primera vez ves el recorrido entero: // cuántos vieron tu video, // cuántos agendaron, // cuántos pagaron. //
Y en qué paso **se te cae la gente**. ///
Cuando alguien deja sus datos, // MaKo le escribe por WhatsApp, // le hace seguimiento si no contesta… //
y te avisa cuando responde. ///
Y si no sabes por dónde empezar, // le preguntas a MaKo. // Conoce tu negocio entero. // Y te dice qué atender hoy.

**PRUEBA (1:30–1:50)** [el funnel real de Mauricio, una sola captura sostenida]
Mauricio venía de meses por debajo de diez mil dólares. ///
En tres meses pasó los **setenta mil**. ///
Sin cambiar la oferta. // Sin cambiar el funnel. // Lo único que cambió: // empezó a decidir con datos.

**OBJECIÓN (1:50–2:05)**
Y si tu objeción es «yo ya tengo un CRM»… // déjame decirte algo: ///
tu CRM guarda nombres. // No sabe de qué anuncio vino cada uno, // cuánto te costó // ni si te pagó.

**OFERTA (2:05–2:15)** [tres tarjetas]
Puedes usar MaKo para tu negocio. // Con tu agencia, para todos tus clientes. //
O entrar al programa grupal: // tres meses de MaKo y asesoría en grupo para dejar tu funnel andando.

**CIERRE (2:15–2:20)**
Escalar no es meterle más dinero a los anuncios. // **Es saber a cuál.** ///
Agenda tu diagnóstico gratis, // aquí abajo.

## 3 ganchos para testear
1. «¿Sabes cuál de tus anuncios te trae clientes?»
2. «Cinco apps. Cinco verdades. Ningún sistema.»
3. «Tu CRM guarda nombres. No sabe quién te pagó.»

## Lo que NO dice, a propósito
- **Precios.** Van en la landing y en la llamada: un video vive meses y el precio se puede mover.
- **Qué trae el grupal** más allá de «tres meses de MaKo y asesoría en grupo»: los entregables los está definiendo el Cerebro.
- **Que MaKo mueve los leads solo** en el CRM: hoy propone y la persona confirma.
- **Garantía**: no hay una decidida para MaKo.
