# VSL · Avatar: infoproductores (los que están en Skool o Hotmart)

> **Para:** el que vende un curso o una membresía y tiene el curso en una plataforma, la comunidad en otra y las ventas en una tercera
> **Ángulo:** tu negocio vive en casa ajena: tu curso, tu comunidad y tus ventas, en un solo lugar tuyo
> **Dura:** ~1:45 · **CTA:** Agenda tu diagnóstico gratis · **Empuja:** el Acelerador (la migración guiada) · **Landing:** `/vsl/infoproductores`

**La idea en una frase:** tus alumnos, tu comunidad, tus cobros y tu funnel de venta viven juntos en MaKo.

## Guion

**GANCHO (0:00–0:12)** [logos de Skool, Hotmart, Stripe y una planilla]
Tu curso está en una plataforma. // Tu comunidad, en otra. // Tus ventas, en una tercera. ///
¿Dónde está **tu negocio**?

**DOLOR (0:12–0:40)**
Cada una te cobra su parte. // Cada una tiene sus alumnos // y sus datos. ///
Y cuando quieres saber qué anuncio te trajo al alumno que más compró… // nadie te lo puede decir. ///
Construiste un negocio… // **en casa ajena.**

**MAKO (0:40–1:18)** [el curso y la comunidad dentro de MaKo]
En MaKo, // tus alumnos entran a tu curso // y a tu comunidad // en un solo lugar. ///
Cobras con tu Stripe // o tu Mercado Pago. // El dinero va directo a ti. ///
Y tu funnel de venta vive al lado: // el anuncio, // la landing, // la llamada // y el alumno que pagó, // conectados.

Un alumno. // De qué anuncio vino. // Cuánto pagó. // Qué clase está viendo.

Y si tu objeción es «migrar es un dolor de cabeza»… // déjame decirte algo: ///
por eso existe el Acelerador: // **la primera semana lo dejamos armado contigo.**

**CIERRE (1:40–1:45)**
Tu audiencia es tuya. // Que tu negocio también lo sea. /// Agenda tu diagnóstico gratis.
