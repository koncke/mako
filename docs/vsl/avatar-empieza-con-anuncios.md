# VSL · Avatar: vende por WhatsApp y quiere empezar con anuncios

> **Para:** emprendedor con una oferta que ya vende por recomendación o en frío, que nunca pautó o pautó y perdió
> **Ángulo:** no le tengas miedo a los anuncios; tenle miedo a pautar sin saber cuánto
> **Dura:** ~1:45 · **CTA:** Agenda tu diagnóstico gratis · **Landing:** por avatar

**La idea en una frase:** MaKo te dice cuánto invertir, qué probar y le escribe a cada lead que llega.

## Guion

**GANCHO (0:00–0:12)** [texto gigante: «¿cuánto?»]
Quieres empezar con anuncios. ///
Y la primera pregunta te frena: // **¿cuánto tengo que invertir?**

**DOLOR (0:12–0:40)**
Alguien te dice cincuenta dólares por día. // Otro, cinco. ///
Pruebas. // Pones un poco en tres anuncios. // Llegan algunos mensajes. // No sabes si estuvo bien. ///
Y cuando te escriben veinte personas el mismo día… // contestas a cinco. ///
El dinero del anuncio // **se quedó en el chat que no abriste**.

**MAKO (0:40–1:18)** [la calculadora de presupuesto, después el lienzo de Automations]
Con MaKo empiezas con una cuenta, // no con una corazonada. ///
Le dices cuánto tienes // y cuánto vale lo que vendes. ///
Y te dice cuántos anuncios probar, // cuánto ponerle a cada uno // y por cuántos días // para que el resultado **signifique algo**. ///
Cuando llegan los mensajes, // cada persona tiene su ficha // y su seguimiento por WhatsApp. ///
Y cuando alguien quiere comprar, // te avisa.

**PRUEBA (1:18–1:30)** [la calculadora con un presupuesto chico]
Quinientos dólares. // Un mes. ///
Tres anuncios, // una semana, // y el resto al que funcionó.

**OBJECIÓN (1:30–1:40)**
Y si tu objeción es «tengo poco presupuesto»… // déjame decirte algo: ///
con poco presupuesto // es cuando **más** importa no tirarlo.

**CIERRE (1:40–1:45)**
Los anuncios no son una apuesta. // Son una cuenta. /// Agenda tu diagnóstico gratis.

## 3 ganchos para testear
1. «¿Cuánto tienes que invertir en anuncios? Hay una cuenta.»
2. «Te escribieron veinte. Contestaste a cinco.»
3. «Con poco presupuesto, más importa no tirarlo.»

## Lo que NO dice, a propósito
- La PRUEBA con US$500 depende del costo por lead: con más de ~US$8 por lead la calculadora propone menos de tres
  anuncios. Antes de grabar, correr la calculadora con el costo real del rubro y ajustar la frase.
- La calculadora entra a producción con la punta 42cc940c6.
