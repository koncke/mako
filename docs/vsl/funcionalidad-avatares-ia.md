# VSL · Avatares de IA

> **Para:** el que sabe que tiene que testear creativos y no tiene tiempo de grabarse · **Ángulo:** más creativos para testear, sin grabarte cada vez
> **Dura:** ~1:35 · **CTA:** Agenda tu diagnóstico gratis · **Empuja:** Pro (AI Avatar) · **Landing:** `/vsl/avatares-ia`

**La idea en una frase:** escribes el guion y MaKo arma el video con tu avatar de IA, listo para tu anuncio.

## Guion

**GANCHO (0:00–0:12)** [una agenda llena con «grabar anuncios» tachado tres veces]
Sabes que tienes que probar más anuncios. ///
Y cada uno // **es una tarde grabándote.**

**DOLOR (0:12–0:35)**
Luz. // Cámara. // Diez tomas para una frase. // Y editar. ///
Así que terminas probando uno. // O dos. ///
Y el anuncio que te iba a cambiar el mes // **nunca se grabó.**

**MAKO (0:35–1:08)** [la tab AI Avatar: el avatar, la voz, el guion]
En MaKo eliges tu avatar // y tu voz. ///
Escribes el guion. // MaKo arma el video. ///
Lo editas ahí mismo // y lo subes a tu anuncio. ///
Diez versiones del mismo mensaje, // con distintos ganchos, // sin volver a prender la cámara.

**PRUEBA (1:08–1:20)** [un guion de tres líneas que se vuelve un video]
Tres líneas de guion. // Un video listo. // Mismo día.

**OBJECIÓN (1:20–1:30)**
Y si tu objeción es «se va a notar que es IA»… // déjame decirte algo: ///
lo que se nota es **un anuncio que no se prueba**. // Testea y que el mercado decida.

**CIERRE (1:30–1:35)**
El que más prueba, // encuentra primero el anuncio que vende. /// Agenda tu diagnóstico gratis.

## 3 ganchos para testear
1. «Cada anuncio nuevo es una tarde grabándote.»
2. «Diez versiones de tu anuncio, sin prender la cámara.»
3. «El anuncio que te iba a cambiar el mes nunca se grabó.»

## Lo que NO dice, a propósito
- ⚠️ **AI Avatar, el 17/10, era sólo para el super admin** («falta verla en pantalla»). Antes de pautar esta landing,
  confirmar que un cliente la ve y que el video sale. Si no, esta landing no se pauta todavía.
