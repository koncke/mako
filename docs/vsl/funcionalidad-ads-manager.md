# VSL · Ads Manager

> **Para:** el que pauta y mira el costo por lead pero no sabe qué anuncio le vende · **Ángulo:** el anuncio más barato no es el que vende
> **Dura:** ~1:45 · **CTA:** Entra a MaKo (o agenda tu diagnóstico) · **Landing:** Ads Manager

**La idea en una frase:** MaKo te muestra cuánto dinero cobrado trajo cada anuncio y te dice cuánto invertir para testear.

## Guion

**GANCHO (0:00–0:12)** [dos anuncios lado a lado]
Tu anuncio más barato // puede ser el que **menos te vende**. ///
¿Lo sabrías?

**DOLOR (0:12–0:38)** [el Administrador de anuncios de Meta, lleno de columnas]
Meta te dice cuánto te costó cada lead. // No te dice cuál de esos leads te pagó. ///
Entonces apagas el que parece caro… // y a veces apagas **el que vendía**. ///
Y cuando quieres probar algo nuevo, // la duda de siempre: // ¿cuánto invierto? // ¿Cuántos anuncios pruebo? ///
Pruebas diez cosas con poco dinero // y no aprendes nada de ninguna.

**MAKO (0:38–1:18)** [la tabla del Ads Manager de MaKo]
En MaKo, al lado de cada anuncio, // ves lo que Meta no te muestra: // cuántas llamadas agendó // y cuánto dinero cobraste de ahí. ///
El que vende, // se queda. // El que solo junta leads, // se va. ///
Antes de lanzar, // le dices tu presupuesto // y cuánto te cuesta un lead. ///
Y MaKo te dice cuántos anuncios puedes probar **con datos suficientes**, // cuánto ponerle a cada uno // y por cuántos días. ///
Y cuando quieres armar una campaña nueva, // la armas conversando con MaKo.

**PRUEBA (1:18–1:30)** [la calculadora con 2.000 dólares]
Dos mil dólares. // Dos dólares y medio por conversación. ///
Tres avatares por tres mensajes, // en una semana. // El resto, // al ganador.

**OBJECIÓN (1:30–1:40)**
Y si tu objeción es «Meta ya optimiza solo»… // déjame decirte algo: ///
Meta optimiza lo que le muestras. // **Si no sabe quién te pagó, optimiza a ciegas.**

**CIERRE (1:40–1:45)**
No necesitas más presupuesto. // Necesitas saber dónde ponerlo. /// Entra a MaKo.

## 3 ganchos para testear
1. «Tu anuncio más barato puede ser el que menos vende.»
2. «¿Cuánto invierto en anuncios? Hay una cuenta.»
3. «Diez pruebas con poco dinero no enseñan nada.»

## Lo que NO dice, a propósito
- La calculadora entra a producción con la punta 42cc940c6: grabar la PRUEBA después de que esté desplegada.
- Que MaKo pausa o escala solo: lo que escribe en Meta pasa por una confirmación.
