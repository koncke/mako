## Lo que este archivo NO reemplaza

El bot que cierra tareas solo. Hoy existe **la mitad del cliente y ninguna del código**:

- **Corriendo:** `app/api/cron/tareas-verificar/route.ts` (cron diario, todos los workspaces activos) cierra tareas contra 13 señales del negocio (`lib/plan-senales.ts:28`) y avisa una vez por día, agrupado. Cuesta cero tokens.
- **El techo, que importa:** `lib/todo-seeds.ts:103` solo mira tareas con `origen === 'mako'` **y que hagan match por título exacto contra el seed**. Una tarea que salió de una reunión, de WhatsApp o escrita a mano NUNCA se autocompleta. Y no mira nada del Ads Manager: ni campaña creada, ni anuncio corriendo, ni presupuesto.
- **Del código, nada:** no hay una sola referencia a git, a commits o a la API de GitHub en `lib/` ni en `app/api/`. Lo único que hay es el canal `cerrar` (migración 0119), donde MaKo propone «esto ya está hecho» con evidencia y el dueño confirma de a una en `/plan/revisar` — pero el que mira el código es Claude Code a mano, no un proceso.
