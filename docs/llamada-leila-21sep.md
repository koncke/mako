## Lo que quedó sin resolver y puede morder

- **La proyección de recurrencia se hizo a 47 USD por cliente, y se cerró en 97.** El número
  de facturación con el que se decidió está calculado con un precio que después cambió (00:21:38).
- **La objeción de Leila que nunca se refutó:** el infoproductor no va a migrar todo para
  después encontrarse con que cuesta 500 cada tres meses. Se esquivó ofreciendo el 97
  mensual — así que si el cliente elige siempre el 97, **la renovación de 500 no existe** (00:13:18).
- **Canibalización:** si el prospecto ve que la app ya hace todo, no compra el programa y
  pide sólo el software (00:39:25).
- **El avatar no está definido:** ¿se acepta gente que todavía no tiene VSL? De eso depende si
  el primer mes es construir desde cero o revisar (01:41:00).
- **«Si va a estar entregando servicio y haciendo marketing, ¿cuándo desarrolla?»** Leila lo
  preguntó y el tema cortó ahí (00:56:00). Es el conflicto de fondo con esta poda.
- **Los cupos:** el VSL grabado dice cinco y se habló de diez (01:21:10).
